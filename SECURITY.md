# Security

Jev my PR stores people's GitHub tokens (encrypted), so security reports are very welcome.

## Reporting a vulnerability

Please **don't open a public issue**. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository. Include what you found, how to reproduce it and what an
attacker could do with it. You'll get a reply as soon as possible, and credit in the fix if you'd like.

## Scope

In scope: this application's code (authentication, authorization between users, token handling, the GitHub and
Jev integrations, usage limits). Out of scope: GitHub, TypeSafe/Jev and other third-party services themselves.
